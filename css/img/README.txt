2. CÓMO INCORPORAR VÍDEOS Y NUEVAS FOTOGRAFÍAS
--------------------------------------------------------------------------------

1. Puedes reemplazar cualquiera de los archivos guardando tus nuevas capturas con el
   mismo nombre en esta carpeta img/.
2. Para insertar un vídeo real (.mp4, .webm) en el visor de #reel de index.html, sustituye
   la etiqueta <img> por la etiqueta estándar <video>:
   <video controls poster="img/frame-ficcion-estudio.jpg" style="width:100%; height:100%; object-fit:cover;">
     <source src="video/mi-cortometraje.mp4" type="video/mp4">
   </video>
3. Para mantener un rendimiento web óptimo y tiempos de carga instantáneos en navegadores,
   se recomienda comprimir las fotos por debajo de 350 KB mediante Squoosh (https://squoosh.app).
